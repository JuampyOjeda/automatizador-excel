# Proyecto 1: Automatizador de archivos Excel/CSV

## Objetivo
Script en Python que procesa archivos Excel/CSV de ventas: detecta errores,
los limpia, genera un reporte en Excel y organiza los archivos por carpeta/fecha.
Es un proyecto de portfolio (nivel inicial), con datos 100% falsos.

## Stack
Python, pandas, openpyxl, faker.

## Estructura
- input/   -> archivos originales
- output/  -> reportes generados
- src/     -> código

## Roadmap
1. Entorno + leer archivo (generar_datos.py ya hecho)
2. Detectar errores (vacíos, duplicados, texto sucio)
3. Limpiar datos
4. Generar reporte Excel (resumen por región/producto/mes)
5. Organizar archivos por carpeta/fecha (shutil)
6. Pulir: README con capturas, logs, subir a GitHub
